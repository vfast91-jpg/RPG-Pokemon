# RPG-Pokemon – Exploration Demo 0.1

Dies ist bewusst **noch kein Kampfsystem**. Die Demo testet nur das Gefühl der Oberwelt: Bewegung, Kamera, Kollisionen, hohes Gras, NPC und Schild.

## So startest du die Demo

1. Auf GitHub oben rechts **Code → Download ZIP** wählen.
2. ZIP entpacken.
3. Im Ordner **`index.html` doppelklicken**.
4. Die Demo öffnet sich direkt im Browser – es ist keine Installation nötig.

## Steuerung

- **WASD** oder **Pfeiltasten**: bewegen
- **E** oder **Leertaste**: mit NPC/Schild interagieren
- **Enter/Escape**: Dialog schließen

## Was diese Version absichtlich nicht enthält

- keine Kämpfe
- kein ATB
- keine Gegnerlisten
- keine Aggro-Werte
- keine Debug-Oberfläche

Ziel von 0.1 ist ausschließlich: **Sieht und fühlt sich das Herumlaufen bereits wie die richtige Richtung für das RPG an?**
